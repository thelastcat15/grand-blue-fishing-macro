# Auto Fishing Bot (GUI)

บอทตกปลาอัตโนมัติ 3 ขั้นตอน พร้อมหน้าต่าง Tkinter ให้ "ลากเมาส์เลือกพื้นที่" บนจอ
แทนการพิมพ์พิกัดเอง

## ติดตั้ง

```bash
pip install -r requirements.txt
```

- Windows / macOS / Linux ใช้ได้หมด
- บน **macOS** ต้องอนุญาต Accessibility และ Screen Recording ให้ Terminal/Python ใน
  System Settings > Privacy & Security ก่อน ไม่งั้น pyautogui/mss จะจับภาพ/คุมเมาส์ไม่ได้

## วิธีใช้

```bash
python gui.py
```

หน้าต่างโปรแกรมจะเปิดขึ้นมา มี 3 ส่วน:

### 1) ตั้งค่าพื้นที่บนจอ
กดปุ่ม **"ลากเลือกพื้นที่บนจอ"** ของแต่ละรายการ — หน้าต่างโปรแกรมจะซ่อนตัวเองชั่วคราว
แล้วจอจะมืดลงเล็กน้อยพร้อมเคอร์เซอร์กากบาท ให้ **ลากเมาส์คลุมกรอบที่ต้องการแล้วปล่อย**
(กด Esc เพื่อยกเลิกการเลือกครั้งนั้น) ต้องเลือกให้ครบ 3 รายการ:

- **หลอดพลัง (โยนเบ็ด)** — กรอบหลอดพลังแนวตั้งตอนคลิกค้างโยนเบ็ด
- **พื้นที่หาไม้ปุ่ม SHAKE** — กรอบกว้างๆ ครอบบริเวณที่ปุ่ม SHAKE อาจสุ่มโผล่
- **แถบตกปลาแนวนอน** — กรอบแถบทั้งแท่ง (รวมไอคอนปลา + แถบดำที่ควบคุม)

### 2) รูปปุ่ม SHAKE
กด **"ลากเลือกปุ่ม SHAKE บนจอ"** แล้วลากคลุมปุ่ม SHAKE ที่กำลังแสดงอยู่บนจอให้พอดี
โปรแกรมจะแคปภาพเก็บไว้เป็นเทมเพลตสำหรับจับคู่ตำแหน่งตอนบอททำงานจริง
(ถ้าปุ่มมีสถานะเปลี่ยนสี/มีเงา ให้เลือกช่วงที่ชัดเจนที่สุด)

### 3) ควบคุมบอท
- **▶ เริ่มบอท** — เริ่มทำงาน (มีเวลา 3 วิให้สลับไปหน้าเกม)
- **■ หยุดบอท** — สั่งหยุดตามรอบถัดไป
- **บันทึกค่าตั้งค่า** — เซฟพิกัดทั้งหมดลง `fishbot_config.json` เพื่อเปิดโปรแกรมครั้งหน้าไม่ต้องเลือกใหม่
- เลื่อนเมาส์ไปชนมุมซ้ายบนสุดของจอ = หยุดฉุกเฉินทันที (pyautogui failsafe)

หน้าต่าง "สถานะ" ด้านล่างจะแสดง log การทำงานแต่ละขั้นตอนแบบเรียลไทม์

## หลักการตรวจจับ

| ขั้นตอน | วิธีตรวจจับ | การกระทำ |
|---|---|---|
| 1. โยนเบ็ด | สัดส่วนพิกเซลสีฟ้าในกรอบหลอดพลังแนวตั้ง | คลิกค้างจนหลอดเต็ม (~97%) หรือค่าหยุดโต แล้วปล่อย |
| 2. หา SHAKE | Template matching หารูปปุ่ม SHAKE ในพื้นที่ค้นหา | คลิกซ้ำจนแถบตกปลา (มีสีเขียวของปลา) โผล่มา |
| 3. ประคองแถบ | ตำแหน่ง x เฉลี่ยของพิกเซลสีเขียว (ปลา) เทียบกับพิกเซลดำ (แถบควบคุม) | ถ้าแถบอยู่ซ้ายกว่าปลา → คลิกค้าง (ไปขวา) ถ้าไม่ → ปล่อย (ไปซ้าย) |

## ปรับจูนเพิ่มเติม

ในหน้าโปรแกรมมีช่อง **"ตั้งค่าขั้นสูง"** ให้ปรับได้เลยโดยไม่ต้องแก้โค้ด:

- **Match threshold ปุ่ม SHAKE** — ถ้าปุ่มจับไม่ค่อยติด ให้ลดค่านี้ลง (เช่น 0.75 → 0.6)
- **Deadzone เฟส 3** — ถ้าแถบดำสั่นถี่/แกว่งเกินไป ให้เพิ่มค่านี้ขึ้น (px กว้างขึ้น = สั่นน้อยลง
  แต่ตามปลาช้าลงนิดหน่อย); ถ้าตามปลาไม่ทัน/หลวมไป ให้ลดค่านี้ลง
- **Cooldown ก่อนโยนเบ็ดใหม่** — เวลาพักหลังตกจบ/หลุด ก่อนเริ่มวนกลับไปโยนเบ็ดใหม่
  ถ้าโยนเบ็ดใหม่เร็วเกินไป (เกมยังไม่จบ animation/ยังไม่พร้อม) บอทจะไปวนหาปุ่ม
  SHAKE ทั้งที่ยังไม่ได้โยนเบ็ดจริง ให้เพิ่มค่านี้ขึ้น (ค่าเริ่มต้น 2 วิ)

ปรับอื่นๆ ที่ต้องแก้ในโค้ด (`bot_core.py`):

- สีที่ตรวจจับผิดเพี้ยน → ปรับค่า HSV ใน `lower_blue/upper_blue` และ `lower_green/upper_green`
- ระยะพยากรณ์ล่วงหน้าในเฟส 3 → ปรับ `reel_lead_time` ใน `fishbot_config.json` (วินาที,
  ค่าเริ่มต้น 0.05) ถ้าคอมช้า/จับภาพหน่วง ลองเพิ่มค่านี้ขึ้นเล็กน้อย

## แก้ปัญหาที่พบบ่อย

**คลิกปุ่ม SHAKE ไม่ติดทั้งที่พิกัดตรงปุ่มพอดี (ต้องขยับเมาส์เองถึงจะคลิกได้)**
เกิดจากเกม (โดยเฉพาะเกมที่ใช้ DirectInput/RawInput) ไม่รับตำแหน่งเมาส์ที่ถูก
"วาป" ไปด้วยคำสั่งระบบตรงๆ โดยไม่มี movement event คั่นกลาง — เกมเลยไม่รู้ว่าเมาส์
เข้ามาอยู่บนปุ่มแล้ว ตัวโปรแกรมนี้แก้แล้วโดยใช้ `input_backend.py` ที่จะขยับเมาส์
แบบมี duration + สั่น 1px ก่อนคลิกทุกครั้ง เพื่อบังคับให้เกิด movement event จริง
ถ้ายังจับไม่ติดอีก แนะนำติดตั้ง `pydirectinput` เพิ่ม (มีอยู่ใน requirements.txt
แล้ว ติดตั้งอัตโนมัติบน Windows) ซึ่งจะถูกเลือกใช้อัตโนมัติแทน pyautogui — ดูว่า
backend ไหนกำลังถูกใช้ได้จากบรรทัดแรกใน log ตอนเริ่มบอท ("มือควบคุมเมาส์: ...")

**เฟส 3 ประคองแถบดำได้ไม่ดี แถบสั่นไปมา**
โค้ดเดิมเป็นแบบคลิก/ปล่อยทันทีที่ error เกิน 0 พิกเซล ทำให้สั่นถี่ตรงกลาง ตอนนี้ปรับ
เป็นระบบ deadzone (โซนกลางไม่สลับสถานะ) + พยากรณ์ทิศทางจากความเร็วการเคลื่อนที่
ล่วงหน้าเล็กน้อย ช่วยให้นิ่งขึ้นและตามปลาได้แม่นขึ้น ปรับค่า deadzone ในช่อง
"ตั้งค่าขั้นสูง" ได้ตามเกม/ความเร็วจอที่ต่างกัน

## ข้อควรทราบ

โปรแกรมนี้อ่านหน้าจอและควบคุมเมาส์เท่านั้น ไม่ได้แก้ไขไฟล์เกมหรือหน่วยความจำของ
โปรเซสเกม แต่การใช้บอทอัตโนมัติอาจขัดกับข้อตกลงการใช้งาน (ToS) ของบางเกม
โปรดตรวจสอบและใช้งานตามดุลยพินิจของตัวเอง
